# GostEspdAddIn

Надстройка (плагин) для Microsoft Word, обеспечивающая автоматическое форматирование выделенных списков и перечислений в соответствии со стандартами ГОСТ ЕСПД (ГОСТ 2.105-2019 и ГОСТ 19.106-78).

Проект выполнен в рамках учебной практики на Факультете компьютерных наук НИУ ВШЭ (2026).

## Возможности
- **Интеллектуальный анализ структуры:** Автоматическая очистка любых графических и ручных маркеров с последующим вычислением уровней вложенности (на базе физических отступов и табуляций). Расстановка тире (`–`) для первого уровня и нумерации со скобкой (`1)`) для вложенных.
- **Контекстная пунктуация и нормализация регистра:** Приведение первых букв к строчному регистру с защитой аббревиатур (например, СУБД, API). Автоматическая расстановка `;` в конце пунктов, `:` перед вложенными списками и `.` в самом конце.
- **Сохранение внутреннего форматирования:** Точечная манипуляция текстом через объекты `Range`, позволяющая внедрять маркеры и менять регистр без разрушения пользовательских стилей (жирный шрифт, курсив, гиперссылки).
- **Строгое форматирование по ГОСТ:** Принудительная установка выравнивания по ширине, межстрочного интервала 1.5 и базового отступа красной строки 1.25 см (с выверенным шагом для последующих уровней вложенности).
- **Атомарность и безопасность:** Обертывание всего алгоритма обработки в единую транзакцию Word API (`UndoRecord`), что позволяет мгновенно отменить весь результат форматирования сочетанием клавиш `Ctrl+Z`.

## Стек технологий
- **Язык программирования:** C#
- **Платформа:** .NET Framework 4.8
- **Технологии:** VSTO (Visual Studio Tools for Office), Word Interop API
- **Развертывание:** ClickOnce (`setup.exe`)

## Установка и использование
1. Распакуйте папку с установочным пакетом (`app.publish`).
2. Запустите исполняемый файл `setup.exe` и подтвердите установку надстройки в MS Word.
3. Откройте MS Word, выделите неформатированный список, перейдите во вкладку **«Надстройки»** и нажмите кнопку **«Оформить по ГОСТ»**.
