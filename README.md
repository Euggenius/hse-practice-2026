# GostEspdAddIn

Надстройка (плагин) для Microsoft Word, обеспечивающая автоматическое форматирование выделенных списков и перечислений в соответствии со стандартами ГОСТ ЕСПД (ГОСТ 2.105-2019 и ГОСТ 19.106-78).

Проект выполнен в рамках учебной практики на Факультете компьютерных наук НИУ ВШЭ (2026).

## Возможности
- **Многоуровневая иерархия и маркеры:** Приведение элементов 1-го уровня к тире (`– `), а элементов 2-го уровня и глубже — к нумерации со скобкой (`1) `, `2) `) с контекстным сбросом и пересчетом счетчиков для каждого подсписка.
- **Очистка маркеров любого типа:** Автоматическая очистка текста от графических маркеров (`•`, `●`, `○`, `■`, `▪`, `▫`, `◦`), дефисов, звездочек, а также ручной цифровой и буквенной нумерации.
- **Интеллектуальное детектирование вложенности:** Вычисление уровня элементов на основе уровней встроенных списков Word, количества начальных табуляций или ранжирования физических отступов абзацев с допуском (`IndentTolerance = 2.0 pt`).
- **Контекстная пунктуация:** Автоматическая расстановка точек с запятой (`;`) в конце пунктов, двоеточий (`:`) перед вложенными списками и финальной точки (`.`) на последнем элементе списка.
- **Обработка вводного текста:** Автоматическое обнаружение вводных фраз, предшествующих спискам, с гарантированной установкой двоеточия (`:`) в их конце.
- **Нормализация регистра с защитой аббревиатур:** Приведение первой буквы элемента к строчному регистру с интеллектуальным сохранением заглавных букв в аббревиатурах и сокращениях (например, СУБД, API, ГОСТ).
- **Сохранение внутреннего форматирования:** Использование точечной манипуляции объектами Range (`WdCharacterCase`) для изменения регистра и вставки маркеров без разрушения стилей текста (жирный шрифт, курсив, гиперссылки).
- **Форматирование абзацев по ГОСТ:** Выравнивание по ширине, межстрочный интервал 1.5, отсутствие интервалов до/после абзаца, базовая красная строка 1.25 см с шагом 0.625 см для последующих уровней.
- **Атомарность операций:** Обертывание всех манипуляций в единый блок `UndoRecord` с поддержкой отмены всех внесенных изменений через `Ctrl+Z`.

## Стек технологий
- **Язык программирования:** C#
- **Платформа:** .NET Framework 4.8
- **Технологии:** VSTO (Visual Studio Tools for Office), Word Interop API
- **Развертывание:** ClickOnce (`setup.exe`)

## Установка и использование
1. Распакуйте папку с установочным пакетом (`app.publish`).
2. Запустите исполняемый файл `setup.exe` и подтвердите установку надстройки в MS Word.
3. Откройте MS Word, выделите неформатированный список, перейдите во вкладку **«Надстройки»** и нажмите кнопку **«Оформить по ГОСТ»**.
